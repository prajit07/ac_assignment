Pipeline Overview

Encoding direction:

Stage Operation
1 Plaintext letters are grouped in pairs and encrypted with a classical Hill Cipher (2x2 matrix, mod 26). Non-letters pass through as literal characters placed between letter groups.
2 The resulting Hill-ciphertext string is converted to its byte values (character codes) and each byte is encrypted independently with S-DES (Simplified DES) using a 10-bit key that generates two 8-bit subkeys, K1 and K2.
3 The doubly-encrypted byte stream is converted to a bit stream, prefixed with a 32-bit length header, and embedded into the least significant bit of the Red/Green/Blue channels of a cover image, one bit per channel, left-to-right, top-to-bottom.
4 The modified image (stego image) is exported as a lossless PNG for download.

Decoding direction reverses each stage: extract LSBs → rebuild bytes → S-DES decrypt with K2 then K1 → Hill-cipher decrypt with the inverse key matrix → original plaintext.
